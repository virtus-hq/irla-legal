# IRLA — legal pages

The privacy policy and account-deletion pages for the IRLA app, published via
GitHub Pages because Google Play requires both to be reachable at public URLs.

This repository is public **only** so that Pages can serve it on a free plan.
It holds nothing but these three pages.

## The canonical copy lives elsewhere

These files are mirrored from `site/` in the private application repository,
which is where they should be edited. Changing them here without changing them
there means the next mirror silently reverts your edit.

## Both URLs must keep working

Google re-checks them for as long as the app is listed, and a dead privacy
policy URL is grounds for removal. Do not rename the files or delete the repo.
